# Advanced-Topics-in-Database-Systems-Project-Group-34

This repository contains our solutions to the requested queries, implemented using PySpark and Apache Sedona.

**Prerequisites:**
=====================================================================

Java/OpenJDK

Python3+pip

Apache Sedona jars (sedona-spark-shaded & geotools-wrapper)

Compatible versions of Apache Spark and Apache Sedona

**Set up instructions**
---------------------------------------------------------------------

1. Clone the repository
2. Give the installer.sh file persmission to execute 
3. Run the install.sh
4. After successfull installation of all the prerequisites run the code for each Query by using
the command

python3 <QueryX.py>
